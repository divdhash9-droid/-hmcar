# HM CAR Auction - دليل التطوير

متجر متخصص في بيع السيارات وقطع غيار السيارات.

## 🚀 بدء التشغيل

### المتطلبات
- Node.js v24.12.0+
- MongoDB 8.2+
- npm أو yarn

### التثبيت والتشغيل
```bash
# تثبيت الاعتماديات
npm install

# تشغيل الخادم
npm run dev

# البيئة المحلية
http://localhost:4001
```

## 📁 الهيكل المنظم

```
├── server.js              # الخادم الرئيسي
├── layout.ejs             # التخطيط العام
├── index.ejs              # الصفحة الرئيسية
└── unified-luxury.css     # الأنماط الموحدة
```

### المجلدات المنظمة
```
├── config/        # الإعدادات
├── models/        # نماذج البيانات
├── routes/        # المسارات
├── middleware/    # البرمجيات الوسيطة
├── services/      # الخدمات
├── views/         # القوالب
└── public/        # الملفات العامة
```

## 🔧 التطوير

### إضافة صفحة جديدة
1. إنشاء ملف EJS في `views/`
2. إضافة المسار في `routes/`
3. إضافة النموذج في `models/` (إذا لزم)

### تعديل التصميم
- تعديل `unified-luxury.css` للأنماط العامة
- تعديل `layout.ejs` للتخطيط العام
- تعديل الصفحة الفردية لتخصيصات محددة

### قواعد البرمجة
- استخدام EJS للقوالب
- Bootstrap 5 للتصميم الأساسي
- Font Awesome 6 للأيقونات
- CSS Variables للتصميم الموحد
