# 🚗 HM CAR - النسخة المنظمة 2.0

## 📋 نظرة عامة

هذا هو المشروع المنظم لمنصة HM CAR لمزادات السيارات، تم إعادة هيكلة بالكامل لتسهيل التطوير والصيانة.

## 🏗️ الهيكل الجديد

```
c:\car-auction\
├── modules/                    # 📦 الوحدات المنظمة
│   ├── core/                  # 🔧 الوحدات الأساسية
│   │   ├── config.js          # إعدادات المشروع
│   │   ├── database.js        # إدارة قاعدة البيانات
│   │   └── logger.js          # تسجيل الأحداث
│   ├── auth/                  # 🔐 وحدات المصادقة
│   │   ├── auth-service.js    # خدمة المصادقة
│   │   └── middleware.js      # الوسطاء
│   ├── services/              # 🛠️ الخدمات
│   │   └── client-service.js  # خدمة العملاء
│   ├── utils/                 # 📚 الأدوات المساعدة
│   │   └── helpers.js         # الدوال المساعدة
│   └── app.js                 # 📱 التطبيق الرئيسي
├── routes/                    # 🛣️ المسارات (القديمة)
├── views/                     # 🎨 القوالب
├── models/                    # 🗄️ نماذج البيانات
├── public/                    # 📁 الملفات العامة
├── server-new.js              # 🚀 ملف الدخول الجديد
└── README-NEW.md              # 📖 هذا الملف
```

## ✨ المميزات الجديدة

### 🏛️ **هيكل منظم**
- **وحدات منفصلة**: كل وظيفة في وحدة خاصة بها
- **تعليقات عربية**: توثيق كامل باللغة العربية
- **كود نظيف**: سهولة القراءة والتعديل
- **قابلية التوسع**: إضافة ميزات جديدة بسهولة

### 🔐 **نظام مصادقة متقدم**
- **دخول العملاء**: بالاسم وكلمة المرور
- **دخول الأدمن**: بالبريد وكلمة المرور
- **تتبع الجهاز**: بصمة فريدة لكل جهاز
- **إدارة الجلسات**: تحكم كامل في الجلسات النشطة
- **صلاحيات دقيقة**: تحكم في صلاحيات كل مستخدم

### 🛡️ **أمان محسّن**
- **حماية CSRF**: حماية من الهجمات
- **Rate Limiting**: تحديد عدد الطلبات
- **تشفير**: حماية البيانات الحساسة
- **تسجيل الأمان**: تسجيل جميع محاولات الاختراق

### 📊 **إدارة متقدمة**
- **لوحة تحكم**: واجهة إدارة متكاملة
- **صلاحيات العملاء**: تحكم كامل في صلاحيات العملاء
- **إحصائيات**: تقارير مفصلة عن النظام
- **بحث وفلترة**: البحث السريع في البيانات

## 🚀 التشغيل

### الطريقة الأولى (الجديدة - موصى بها):
```bash
# تشغيل النسخة المنظمة
npm run start:new

# أو مباشرة
node server-new.js
```

### الطريقة الثانية (القديمة):
```bash
# تشغيل النسخة القديمة
npm start
```

## 📚 الوثائق

### الوحدات الأساسية

#### 📁 `modules/core/config.js`
- جميع إعدادات المشروع
- إعدادات قاعدة البيانات
- إعدادات الأمان
- إعدادات الخادم

#### 📁 `modules/core/database.js`
- إدارة الاتصال بقاعدة البيانات
- معالجة الأخطاء
- أحداث الاتصال

#### 📁 `modules/core/logger.js`
- تسجيل الأحداث
- تسجيل الأخطاء
- تسجيل العمليات الأمنية

### وحدات المصادقة

#### 📁 `modules/auth/auth-service.js`
- خدمات المصادقة
- تسجيل الدخول والخروج
- إدارة الجلسات
- بصمة الجهاز

#### 📁 `modules/auth/middleware.js`
- الوسطاء (middleware)
- التحقق من المصادقة
- التحقق من الصلاحيات
- حماية المسارات

### الخدمات

#### 📁 `modules/services/client-service.js`
- إدارة العملاء
- الصلاحيات
- الجلسات
- الإحصائيات

### الأدوات المساعدة

#### 📁 `modules/utils/helpers.js`
- دوال التنسيق
- دوال التحقق
- دوال المعالجة
- أدوات متنوعة
