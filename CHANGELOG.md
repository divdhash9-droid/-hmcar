# Changelog

All notable changes to HM CAR will be documented in this file.

## [2.0.0] - 2026-02-09

### 🚀 Major Release - Complete System Modernization

#### Added
- **Next.js 16 Frontend** - Modern React-based frontend with App Router
- **API v2** - Complete RESTful API with JWT authentication
- **New Features**:
  - 🔨 Live Auction System with real-time bidding
  - ❤️ Favorites System
  - ⚖️ Car Comparison Tool
  - 💬 Messaging System
  - ⭐ Reviews & Ratings
  - 📧 Contact Form

#### Changed
- Migrated from EJS templates to Next.js
- Restructured backend with modular architecture
- Updated to Tailwind CSS v4
- Improved API response format

#### Removed
- Old EJS template system
- Legacy server.js
- Outdated documentation

#### Security
- JWT-based authentication
- Rate limiting on all endpoints
- Input sanitization
- CORS configuration

## [1.x.x] - Previous Versions

Legacy versions using EJS templates (no longer supported).
