# 🤝 Contributing to HM CAR

Thank you for your interest in contributing to HM CAR!

## 📋 Development Process

1. **Fork** the repository
2. **Clone** your fork locally
3. **Create a branch** for your feature/fix
4. **Make changes** following our coding standards
5. **Test** your changes
6. **Submit** a pull request

## 🌿 Branch Naming

```
feature/description   # New features
fix/description       # Bug fixes
docs/description      # Documentation
refactor/description  # Code refactoring
```

## 📝 Commit Messages

Use clear, descriptive commit messages:

```
feat: add car comparison feature
fix: resolve auction timer issue
docs: update API documentation
style: format code with prettier
refactor: simplify authentication flow
```

## 🧪 Testing

Before submitting:

```bash
# Run tests
npm test

# Check linting
npm run lint
```

## 📁 Code Organization

- **Backend code** goes in `routes/`, `models/`, `services/`
- **Frontend code** goes in `client-app/src/`
- **Documentation** goes in `docs/`

## 🎨 Styling Guidelines

### CSS/Tailwind
- Use the established color palette
- Maintain dark theme consistency
- Use existing utility classes

### JavaScript/TypeScript
- Use meaningful variable names
- Add comments for complex logic
- Follow existing patterns

## 🔍 Code Review

All PRs will be reviewed for:
- Code quality
- Test coverage
- Documentation
- Performance impact
